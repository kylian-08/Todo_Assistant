提醒可靠性

提醒到点不响？请按以下设置确保后台可靠触发：

  • 通知权限：允许本应用发送通知
  • 电池策略：系统设置 → 应用 → TODO Assistant → 电池 → 选「无限制 / 允许后台活动」
  • 自启动：小米 / 华为 / OPPO / vivo 等机型，在「自启动管理」中允许本应用
  • 精确闹钟：已内置精确闹钟权限，系统会按时唤醒（无需手动开启）

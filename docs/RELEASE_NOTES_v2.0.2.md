# TODO Assistant · v2.0.2

**桌面端功能对齐移动端**

发布日期：2026-06-25 · versionCode 4 / versionName 2.0.2

---

## 亮点速览

本次将移动端已有、而 Windows 桌面端缺失的功能补齐，让两端体验一致。

### 🗓️ 桌面日历视图

在顶部「列表 / 看板」旁新增「**日历**」：

- 月历格高亮**当天**与**有计划的日期**（按 Bug / 待办 / 需求 / 灵感 显示彩色圆点）。
- 点击任意日期，右侧面板列出当天计划；点击计划直接进入编辑。
- **+ 新建计划**：在左侧录入栏自动预填该日提醒时间（今天默认 1 小时后，其它日期默认 09:00）。
- 完全跟随主题（浅色 / 深色）与界面风格（玻璃拟态 / 极简杂志 / 扁平素色）自适应。

### ⌨️ Esc 关闭浮层

对应移动端返回键：按 **Esc** 依次关闭 图片预览 → 版本历史 → 设置 浮层。桌面端关闭主窗口本就最小化到托盘常驻，等价于移动端的「后台保活」。

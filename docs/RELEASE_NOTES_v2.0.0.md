# TODO Assistant · Android v2.0.0

**移动端重构 + 统一外观系统**

发布日期：2026-06-25 · 分支：`android` · versionCode 2

---

## 亮点速览

这是 Android 分支自首次发布以来最大的一次更新。我们重写了移动端的整套交互，并新增了一套桌面与移动端通用的「外观系统」，让你可以自由定制主题、风格与背景。

### 🎨 统一外观系统（桌面 + 移动通用）

| 维度 | 选项 |
|------|------|
| 明暗主题 | 浅色 · 深色 · 跟随系统 |
| 界面风格 | 玻璃拟态 · 极简杂志 · 扁平素色（两端可各自独立选择） |
| 自定义背景 | 背景图（自动压缩）· 模糊度 · 透明度 · 底色 |

- 在「设置 → 外观」中即时预览，所有选择自动保存在本地。
- 风格按当前设备分别记忆：桌面与手机可以是不同风格。

### 📱 全新移动端交互

- 底部 **Tab Bar**（列表 / 看板 / 日历 / 统计）+ 右下角 **FAB** 新建。
- **底部弹出式录入表单**，单手操作更顺手。
- 看板用**状态切换按钮**替代触屏上不可靠的拖拽。
- **日历视图**：高亮有计划的日期，点选查看或直接新建当日计划。

### 🔔 Android 原生定时提醒

到期时通过系统通知提醒，无需常驻前台。

## 修复

- 解决移动端按钮点击无响应 / 错位 / 双击等触摸问题。
- 修复列表卡片标题在窄屏被挤成竖排文字。
- 日历页隐藏冗余 FAB，避免遮挡。
- 桌面 / 移动样式彻底隔离，互不影响。

## 升级与安装

```bash
git checkout android
npm install
npm run cap:prepare
# 在 android/ 下构建 release（需配置 keystore.properties）
cd android && ./gradlew assembleRelease
```

产物：`android/app/build/outputs/apk/release/app-release.apk`

> 数据存储在本地 IndexedDB，增量安装（`adb install -r`）不会丢失既有留档。
